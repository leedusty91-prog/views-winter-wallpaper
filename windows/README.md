# Windows 安装

1. 安装 [Lively Wallpaper](https://github.com/rocksdanister/lively)。
2. 用 `render/encode.sh` 导出的 `views-storm-1920x1080-h264.mp4`，或者直接拖进 Lively。
3. 命令行设置（PowerShell）：

```powershell
& 'C:\Program Files\Lively Wallpaper\Lively.exe' setwp --file 'C:\path\to\views-storm-1920x1080-h264.mp4'
& 'C:\Program Files\Lively Wallpaper\Lively.exe' app --volume 0
```
